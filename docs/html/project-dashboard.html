每日视察重点

1. 先看 git 是否干净

重点判断有没有未提交改动、本地是否领先远端、最近提交是否都是你认可的工作。

2. 再看当前主线是否变化

当前主线是把文字/转写输入下的记忆、召回、解释、删除、评估做稳，不是重写记忆系统。

3. 看昨天附近完成了哪批

用最近提交确认是否刚做过周报、source summary、target eval、timeline evidence 管理等能力。

4. 看今天最适合继续哪里

如果继续产品化，优先真实口语 target、周报/注意事项入口、evidence 解释和用户管理闭环。

git status --short --branch
git log --oneline --decorate -10

当前巡检时看到：dev_ykhu 与 nreal/dev_ykhu 已对齐，工作区没有未提交文件。以后每天仍以命令输出为准。

当前阶段判断

层级 状态 怎么理解
文字记忆内核 第一版闭环 写入门控、语义去重、纠错、evidence、召回仲裁、strength、observation scope、timeline 管理和机制级 eval 已有当前实现。
Web demo 产品化 第一版可用 聊天、浏览器语音、文档导入、capture、source summary、最近 audit 回放、周报草稿和提醒检查已能演示，但仍是本地 demo。
真实 AI 眼镜产品 未生产化 还没有真实硬件 runtime、原生 App、音频上传/ASR、主动推送、多设备同步、账号权限和可靠队列。

输入Web 文字、浏览器语音、Markdown、转写后文本、capture
路由planner fast path + structured router + temporal/parser
召回profile、event、timeline、document、location、web
回复本地回复或 Hermes AIAgent，优先让用户先看到结果
沉淀后台记忆 job、observation reflect、debug/audit/eval

能力地图

能力 当前状态 视察时看什么
主聊天闭环 已闭环 /api/chat、planner/router、召回、回复、后台写入、audit 是否仍能跑通。
原文 timeline/evidence 基础闭环 能不能查原话、查看 evidence、删除后不再被 active 召回。
文档与 App 文本入口 后端雏形 Markdown 和转写后文本能否进入统一记忆管道，不要误认为已有原生 App。
长输入 capture 基础门禁 会议记录、项目复盘等长文本是否低打扰回复并后台沉淀高价值信息。
周报和注意事项 第一版 自然问“这周进展如何”“接下来注意什么”时是否走启发式周报/任务风险召回。
提醒 仅手动检查 /api/reminders/check 不是主动提醒 runtime，不能当成推送能力完成。
eval 覆盖 机制较强，场景仍弱 active gate 保护文字记忆机制；真实眼镜口语、ASR 噪声、主动服务仍多为 target/known gap。

不能误判为已完成

浏览器语音不是硬件方案

它只是 demo 输入，不能代表真实眼镜采集、断句、ASR、说话人和音频证据。

周报不是项目管理系统

/api/weekly-report 是启发式草稿，不是完整项目知识图谱或工作流平台。

提醒检查不是主动推送

现在是手动检查候选，缺授权、触发窗口、勿扰、抑制和推送通道。

target eval 不是门禁通过

target 用于暴露产品缺口，只有升为 active 后才是严格回归门禁的一部分。

SQLite job 不是可靠队列

job/capture 有最小持久化状态，但没有 worker 重放、跨进程调度和生产监控恢复。

observation 不是图谱/向量库

它是轻量长期归纳，只服务明确回顾问题，不是默认注入全部上下文。

下一步优先级

方向 建议动作 成功标准
继续底层记忆机制 不要重复做已进 active 的生命周期、dedupe、纠错、仲裁和长输入基础链路；优先补真实 AI 眼镜高频 target。 新增场景能暴露口语碎片、ASR 噪声、跨来源组合、用户纠正和来源删除问题。
继续 demo 产品化 打磨周报、注意事项、source summary、evidence 解释和删除后的可见反馈。 用户不用看 debug，也能知道回答依据来自记忆、文档还是原文证据。
准备真实产品层 先设计音频上传/ASR、App 输入、主动提醒授权和推送策略，不要另起一套记忆系统。 真实输入端复用当前文字记忆管道，保留门控、audit、evidence 和 eval。

cd /Users/huyaokai/Desktop/workspace/hermes-agent
conda run -n hermes python -m unittest discover ai_glasses_memory_assistant/tests -q
cd /Users/huyaokai/Desktop/workspace/hermes-agent
conda run -n hermes python -m ai_glasses_memory_assistant.evals.runner --mode live --repeat 3 --strict
